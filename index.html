01 / APRENDIZAJE

Lo visto en clase

Fundamentos

El cableado estructurado permite organizar las conexiones y los equipos de una red. La identificación correcta de cada elemento facilita el mantenimiento, la administración y la detección de fallas.

Organización

Ubicar cada equipo en su unidad U y documentar su posición.

Identificación

Registrar nombres, modelos, conexiones y datos disponibles.

Documentación

Mantener el inventario actualizado y conservar copias de respaldo.

02 / INFRAESTRUCTURA

Las tres capas del inventario

Física · Lógica · Eléctrica
01

Capa física

Ubicación U, nombre del equipo, modelo y ocupación del rack.

Ejemplo: U25 · Cisco ISR 4331
02

Capa lógica

VLAN, dirección IP y función de red cuando están documentadas.

Ejemplo: VLAN 10, 20 y 30
03

Capa eléctrica

Alimentación y relación con la PDU. Los datos deben verificarse físicamente.

Ejemplo: PDU Quest
Normas de referencia

ANSI/TIA-606 para la administración e identificación de la infraestructura y ANSI/TIA-568 para el cableado de telecomunicaciones. La aplicación concreta debe verificarse según el alcance de cada norma.

03 / PROCEDIMIENTO

Actividad realizada

Inventario
  1. Organizar los equipos según la unidad U registrada.
  2. Relacionar la información física, lógica y eléctrica disponible.
  3. Representar gráficamente las 28U del rack.
  4. Implementar consulta, edición, registro y eliminación de equipos.
  5. Probar las validaciones y las funciones de respaldo JSON.

Los resultados de las pruebas deben corresponder a lo verificado en el navegador y en los archivos del proyecto.

10 / CONSULTA

Glosario y fuentes

Referencias

Unidad U

Medida vertical utilizada para expresar la altura de equipos de rack.

VLAN

Red de área local virtual que permite segmentar una red lógica.

IP

Dirección utilizada para identificar una interfaz dentro de una red IP.

PDU

Unidad de distribución de energía eléctrica para equipos.

Inventario JSON

Archivo estructurado que almacena la configuración del rack y sus equipos.

Fuentes de consulta

  • Telecommunications Industry Association (TIA) — información institucional sobre normas de telecomunicaciones.
  • MDN Web Docs: JavaScript — referencia de programación web.
  • MDN Web Docs: JSON — documentación sobre el formato de datos JSON.
  • Documentación oficial de GitHub — repositorios y control de versiones.

Las fuentes son referencias generales. Para una entrega técnica, consulta la versión aplicable de cada norma y verifica los datos del laboratorio con evidencia real.
